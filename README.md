# Call Insight AI

Сделай простое веб-приложение “AI-анализ звонка” (только фронтенд). Обработка аудио/текста и генерация анализа будут выполняться на моём бэкенде позже, поэтому сейчас нужен только UI, состояния и обработка ошибок. Одна страница, аккуратный современный дизайн.

Верх экрана — 2 колонки

Слева:

Большое поле-квадрат для ввода.
Внутри текст: “Переместите сюда аудиофайл и получите анализ звонка”
Подпись: “Форматы: mp3, wav, m4a, ogg”
В это же поле можно вставить текст (например расшифровку звонка). Если вставлен текст — файл не обязателен.
Пользователь может: перетащить файл / нажать и выбрать файл / вставить текст (Ctrl+V).
Показывай, что выбрано: либо имя файла, либо “Вставлен текст”.
Кнопка “Очистить” очищает и файл, и текст.
Если формат файла не подходит — покажи подсказку прямо у поля загрузки (например “Неверный формат, загрузите mp3/wav/m4a/ogg”).
Кнопка “Запустить анализ”.
Кнопка всегда кликабельна.
Если нет ни файла, ни текста — при клике ничего не запускай и покажи подсказку рядом с кнопкой: “Добавьте файл или вставьте текст”.
Если есть текст или файл — то кнопка работает и выелючается состояние “Обрабтываю”
Справа:
 Блок “Критерии” со списком критериев, которые можно удалять и добавлять.По умолчанию 3 критерия (их тоже можно удалять):
Приветствие
Выявление проблемы
Обработка возражений
Ниже поле “Новый критерий” и кнопка “Добавить”.
Кнопка “Добавить” всегда кликабельна.
Если поле пустое — при клике покажи подсказку рядом: “Введите название критерия”.
Если текст введён — добавляй новый критерий в список.
Низ страницы — результат

Сделай блок “Результат анализа” на всю ширину.Пока результата нет — показывай подсказку: “Загрузите файл или вставьте текст и запустите анализ”.

Ниже оставь место под будущий результат (пустой контейнер/карточка), чтобы потом туда будет подставляться анализ с бэкенда.

Под блоком кнопка “Скачать PDF”.

Кнопка всегда кликабельна.

Если анализа ещё нет — при клике показывай подсказку рядом: “Сначала получите результат анализа”.

Пока анализа нет — PDF не формируется.

Состояния (показывай на экране)

“Получили” — когда добавлен файл или вставлен текст.

“Обрабатываю…” — после нажатия “Запустить анализ”:

покажи спиннер/индикатор и текст “Обрабатываю…”

во время обработки: если нажимают на любую кнопку, показывай подсказку “Идёт обработка, подождите”

“Готово” — состояние для будущего: когда результат анализа появится и PDF можно скачать (пока просто предусмотрись в логике/UI, но без генерации).

Не реализовывай обработку, пока что сделай только красивую фронтальную часть

Подключи фронт к моему бэкенду (Google Colab). Все запросы идут по одной публичной ссылке.

1) Адрес бэкенда

Единственный endpoint: https://purple-jerry-folding-prefer.trycloudflare.com/analyze

2) Что фронт должен отправлять 

Отправляй запрос в формате form-data (multipart/form-data), потому что он подходит и для текста, и для аудио.

Имена полей form-data должны быть ровно такие:

file — аудиофайл (если анализ по аудио)

text — текст диалога (если анализ по тексту)

criteria — строка со списком критериев в виде JSON-строки массива

Как отправлять критерии:

В запросе form-data поле criteria должно быть строкой, то есть результатом “превращения массива в строку”.

Пример значения criteria (именно строка):
 ["Приветствие","Выявление проблемы","Обработка возражений"]

Правило выбора ветки:

Если пользователь прикрепил файл → отправляй file + criteria (и не отправляй text)

Если пользователь вставил текст → отправляй text + criteria (и не отправляй file)

Важно: при отправке FormData не выставляй вручную заголовок Content-Type — браузер сделает это сам.

3) Что бэкенд возвращает (и как это отображать)

Бэкенд всегда возвращает JSON.

Успех (HTTP 200):

status = "ok"

analysis = строка с итоговым анализом

Поведение фронта при успехе:

поставить состояние “Готово”

показать analysis в блоке “Результат анализа” (прямо как текст)

включить логику кнопки “Скачать PDF” (PDF делай на фронте из текста analysis)

Ошибка (HTTP 400/500/503):

status = "error"

message = понятный текст ошибки (его нужно показать пользователю)

Поведение фронта при ошибке:

вернуться в состояние “Получили” (или оставить как есть, но убрать “Обрабатываю…”)

показать message рядом с кнопкой, которая запускала действие (например рядом с “Запустить анализ”). Если пользователь загрузил файл (аудио) в область ввода, рядом с названием загруженного файла должен отображаться небольшой значок, указывающий тип содержимого:

иконка аудио, если загружен аудиофайл;

иконка текста, если анализ будет проводиться по вставленному тексту (при сценарии без файла, если такой предусмотрен).

Иконка должна обновляться при смене файла или способа ввода.

Ожидаемый результат:
После выбора файла пользователь видит название файла и соответствующую иконку, по которой однозначно понятно, что загружен именно аудиофайл. При использовании текстового режима пользователь видит иконку текста.
